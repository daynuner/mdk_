ПРОЕКТ «КАЛЬКУЛЯТОР» — ЛАБОРАТОРНАЯ РАБОТА № 2

Состав файлов
-------------
calculator_core.py  — вычислительные функции, операции памяти и CalculatorEngine.
calculator_app.py   — графический интерфейс приложения на Tkinter.
test_calculator.py  — 20 модульных и интеграционных тестов unittest.

Требования
----------
Python 3.10 или новее. Дополнительные сторонние библиотеки не требуются.
Для запуска графического приложения в среде Python должен быть доступен Tkinter.

Запуск приложения
-----------------
Сохраните все три файла в одном каталоге и выполните:
    python calculator_app.py

Поля A и B используются для ввода операндов. Бинарные операции работают с A и B,
унарные операции (квадратный корень и факториал) — с A.

Команды памяти
--------------
MS — сохранить значение из поля A в память.
MR — прочитать память и поместить значение в поле A.
M+ — прибавить значение из поля A к памяти.
MC — очистить память.

Запуск тестов
-------------
В каталоге проекта выполните:
    python -m unittest -v

Результат проверки в среде подготовки: 20 тестов пройдены успешно (OK).
Дополнительно выполнена проверка создания окна и основных обработчиков Tkinter.
